# Ragnarok Survivors — Chronicles of Rune-Midgards

**Play directly in your browser:** [https://wosupport.github.io/ragnarok-survivors/](https://wosupport.github.io/ragnarok-survivors/)

An action roguelite survivor game inspired by [Azeroth Survivors](https://wow.aethus.pl/) and built with authentic **Ragnarok Online** sprites, skill & item icons, Monster Card illustrations, map textures, overhead minimaps, `.wav` sound effects, and SoundTeMP BGM tracks.

## Features
- **6 Transcendent Job Classes (Male & Female)**: Lord Knight, High Wizard, Sniper, Assassin Cross, High Priest, and Champion — each with unique base stats, auto-casting starter skill, and `F` mobility skill unlocked at Base Lv.5.
- **17 Auto-Casting RO Skills & Transcendent Evolutions**: Bowling Bash, Storm Gust, Meteor Storm, Double Strafe, Falcon Blitz, Sonic Blow, Grimtooth, Magnus Exorcismus, Asura Strike, and more — evolve Lv.5 skills with matching passives.
- **6 Classic Midgard Battlegrounds**: South Prontera Field (`prt_fild08`), Payon Haunted Cave (`pay_dun00`), Morroc Pyramids (`moc_pryd01`), Geffen Nightmare Depths (`gef_dun01`), Orc Village Warfront (`gef_fild10`), and Glast Heim Chivalry (`gl_knt01`) with Mini-Bosses & MVPs every 2 minutes.
- **Permanent Meta-Progression**: Loot Zeny to unlock **Kafra Corporation Blessings** and collect/craft 12 authentic 300×400 **RO Monster Cards** to slot before runs.

## Controls
| Input | Action |
| --- | --- |
| `W A S D` / Arrow Keys / Touch Joystick | Move |
| `Space` | Tactical Hop |
| `F` | Class Mobility Skill (unlocks at Base Lv.5) |
| `1` / `2` / `3` | Pick Level-Up Upgrade Card |
| `C` | Toggle Classic RO Isometric Camera Tilt |
| `Mouse Wheel` | Camera Zoom |
| `Esc` | Pause |

## Run Locally
```bash
npm run dev
# Opens at http://localhost:5173
```
